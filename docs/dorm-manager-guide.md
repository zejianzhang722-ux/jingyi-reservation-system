# 宿管小程序：现场服务操作说明

## 清晰分组

登录后进入工作台，仅展示今日概览与四个功能入口，不混入长列表或操作表单。

| 独立页面 | 用途 | 主要操作 |
| --- | --- | --- |
| 工作台 | 今日概览、统一入口 | 选择所需功能 |
| 预约查询 | 查看负责楼栋的房间、日期、时段、预约人、人数和用途 | 日期与状态筛选、搜索、翻页 |
| 扫码办理签到 | 核对宿生身份，办理签到并提供开门信息 | 扫码、身份确认、确认签到 |
| 空间监控 | 查看现在各房间的使用安排，辅助巡房 | 状态筛选、房间查找、刷新 |
| 签到记录 | 查询签到、重复操作、异常及跟进结果 | 结果筛选、按预约编号查询 |

子页面使用微信顶部返回按钮回到工作台。返回时重新读取最新状态。

## 适老化设计要求与本次落实

- 普通正文约17像素，辅助文字不小于15像素；房间、时间、楼栋进一步放大。
- 按钮高度至少48像素，整张功能入口均可点击；筛选控件上下排列，减少误触。
- 深色文字配浅色卡片，白色文字配深青色主按钮；状态同时用文字和颜色说明。
- 一张预约卡片只呈现一条预约，优先显示房间和时间；不使用密集表格或横向滚动。
- 常用签到流程只有扫码、核对身份、确认签到三步；没有技术字符串输入步骤。
- 扫码失败提示允许相机、重新扫描宿生最新动态码；仍失败联系书院导生会会长团。
- 不显示与现场任务无关的权限说明，不使用内部角色编号代替实际楼栋名称。
- 网络提交结果不明时保留原操作并提供重试，避免重复签到。

## 签到与开门

宿生从预约详情打开动态预约码。宿管扫码后核对预约人现场身份，勾选身份一致，再点击“核验通过并签到”。成功页显示实际房间位置、日期、使用时段、预约人、脱敏学号、人数、用途和登记时间。确认信息后由宿管现场开门；本次未接入自动门禁控制。

身份或现场情况异常时填写异常说明，点击“登记异常，不办理签到”，并联系书院导生会会长团。取消相机不会办理签到。重复扫码只展示已有签到结果，不会新增一次签到。

## 空间监控的含义

状态依据系统预约与签到记录计算，不是摄像头监控或门禁传感器实时占用：

- 已签到·使用中：有签到记录，需要时可查看房间、人员和时段。
- 当前有预约·待签到：处于预约时段，但尚未办理签到。
- 当前无使用记录：没有当前预约或签到占用记录，不能据此保证现场绝对无人。
- 当前未开放：房间关闭或不在开放时段。
- 时段已结束·待巡房核实：签到记录仍显示使用中但预约已过时，提醒现场巡房。

页面每15秒更新，仅在当前页面可见时刷新。网络失败会提示状态可能过时，不能仅凭旧状态开门。
