# 小程序管理员工作台指标卡导航设计

日期：2026-07-22

## 目标

把管理员工作台上的统计卡片从纯展示信息改为可执行入口。管理员点击数字卡后，应进入与该指标对应的完整清单，并自动应用正确筛选条件，同时保留返回工作台的路径。

本次沿用现有小程序视觉体系和页面结构，不新增重复的“指标详情”页面。

## 角色与数据范围

- 导生管理员只能进入普通审批及其账号楼栋范围内的预约、使用中预约和开放功能房清单。
- 辅导员可以进入普通审批和重点审批清单，并查看其授权范围内的数据。
- 超级管理员拥有全部入口和全院数据范围。
- 待处理反馈入口仅对具有反馈管理权限的账号显示。
- 首页隐藏入口不能替代目标页面验权；每个目标页面仍须独立校验登录状态、角色和数据范围。

## 指标到页面的映射

| 工作台指标 | 目标页面 | 自动筛选 |
| --- | --- | --- |
| 普通待审 | 全部预约 | 普通待审批 |
| 重点待审 | 全部预约 | 待辅导员审批 |
| 可处理待审 | 全部预约 | 当前账号全部可处理事项 |
| 今日预约 | 全部预约 | 当日预约 |
| 使用中 | 全部预约 | 使用中 |
| 开放房间 | 功能房管理 | 开放中 |
| 待处理反馈 | 反馈管理 | 待处理 |

“当前账号全部可处理事项”由后端按照当前角色和楼栋范围计算，不能只在前端截取一页数据后过滤。

## 交互设计

- 可跳转卡片显示方向提示，并具有按压反馈，整体点击区域不少于现有卡片面积。
- 使用普通页面跳转进入清单，返回时仍回到工作台原位置。
- 点击期间设置短暂导航锁，避免连续点击打开多个相同页面。
- 统计首次加载中或没有可信结果时，卡片不执行跳转；点击时提示先重新加载数据。
- 已保留上次可信统计但本次刷新失败时，允许进入清单；清单以实时请求结果为准。
- “待处理反馈”卡片中的“重新加载”操作只刷新统计，不触发页面跳转。
- 无权访问的入口继续隐藏；若登录状态或角色在点击前变化，则停止跳转并回到登录页或刷新当前角色状态。

## 目标页面行为

### 全部预约

- 支持从页面参数读取预设筛选条件。
- 页面标题或筛选区域明确显示当前筛选，避免管理员误以为正在查看全部数据。
- 支持普通待审、重点待审、全部可处理、今日预约、使用中和全部预约。
- 重点待审项目仍必须进入详情后审核，不提供首页式快捷通过。
- 管理员手动切换筛选后，后续加载继续使用新的筛选条件。

### 功能房管理

- 支持“开放中”预设筛选。
- 从工作台进入时只显示开放房间，管理员仍可切回全部或其他现有分类。

### 反馈管理

- 支持“待处理”预设筛选。
- 只对有反馈管理权限的账号开放。

## 数据与接口

- 继续使用现有预约、功能房和反馈接口。
- 预约接口增加明确的“当前账号可处理”筛选语义，由服务端按角色、楼栋和审批层级限制结果。
- 今日预约使用本地日期生成明确日期参数，服务端继续执行数据范围限制。
- 所有筛选参数采用白名单，不识别的参数退回安全的默认列表。

## 错误处理

- 目标清单请求失败时显示可理解的失败状态和重新加载入口，不显示空列表冒充成功。
- 页面参数与当前权限不匹配时，不请求越权数据；显示无权访问提示或回到可访问的默认筛选。
- 导航失败时释放导航锁，并提示管理员重试。

## 验收标准

- 七类可见指标卡均能进入正确清单并应用对应筛选。
- 导生管理员、辅导员和超级管理员看到的入口、审批层级和数据范围均正确。
- 连续快速点击不会打开重复页面。
- 无可信统计时不会误跳转；保留可信旧数据时仍可进入实时清单。
- 反馈重试按钮不会同时触发卡片跳转。
- 返回操作能回到原工作台。
- 后台网页与小程序仍使用一致的状态字段和审批含义。
- 相关小程序回归、跨端一致性、权限和语法检查全部通过。
