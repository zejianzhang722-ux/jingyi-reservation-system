# 小程序登录页视觉升级设计

## 目标

将当前偏普通的深蓝登录页升级为具有明确品牌识别的“星环空间”视觉。页面需要体现敬一书院的文化归属、功能房预约平台的数字化属性和可信赖的服务感，同时保持学生与管理员登录流程不变。

## 品牌标志

- 以用户提供的敬一书院官方标志为唯一图形原型。
- 保留原标志近完整圆环、右侧开口、中央横向笔形结构及尖角关系。
- 不直接裁切、贴入或描摹原 JPG；使用 ImageGen 重绘为独立的透明背景资产。
- 定稿材质为高级 3D 光学玻璃，主色为冰蓝、深海青和低饱和松石色，可使用极少量香槟色高光。
- 登录页使用“图形标 + 敬一书院 + 功能房预约平台”的组合；图形本身不包含生成式文字，避免文字失真。
- 输出文件放置在 `miniapp/images/brand/`，至少包含登录页高清图形标。原始生成文件保留，不覆盖用户提供的源图片。

## 整体视觉

- 风格：深海数字空间、精密光学玻璃、克制科技感。
- 主背景：`#061426` 至 `#0B2A46` 的深海蓝渐变。
- 主强调色：冰蓝 `#67DDE1`、青绿 `#54CFC5`。
- 辅助高光：香槟白 `#F5E9BE`，仅用于标志反光和极少量提示。
- 文字：标题使用高对比白色，正文使用蓝灰色，避免当前低对比灰字。
- 背景视觉由一组大型玻璃空间环、精细网格、柔和光晕和少量漂浮光点构成，不继续使用粗糙的大圆形色块。

## 页面布局

1. 顶部区域与页面背景统一为深海蓝，避免现有亮蓝色导航栏割裂画面。
2. 品牌区位于首屏上部：3D 玻璃标志为视觉中心，下面依次显示“敬一书院”“功能房预约平台”和简短品牌说明。
3. 登录卡片位于首屏中部偏下，采用半透明深色玻璃面板，并通过边缘高光、内阴影和背景模糊建立层次。
4. 学生/管理员切换使用双段式选择器，选中态为青色玻璃滑块，未选中态保持清晰可读。
5. 输入框必须显示固定字段标签与占位提示，图标使用统一线性风格；聚焦态出现清晰的青色边框与微光。
6. 主按钮使用冰蓝到青绿色的横向渐变，保持不少于 88rpx 的触控高度；按下时只做轻微下沉和亮度变化。
7. 首次使用提示放在卡片下方，改为清晰的辅助链接式信息，不使用过淡的小字。
8. 页面在常见手机高度下无需滚动即可完成主要登录操作；小屏设备允许自然滚动，内容不得被底部安全区遮挡。

## 动效

- 页面进入时：背景光环淡入并缓慢旋转，品牌标志从轻微缩放和模糊状态清晰出现，登录卡片随后上移淡入。
- 标志保持低幅度悬浮与折射高光扫过，周期较长，避免廉价闪烁感。
- 登录模式切换保持 250 至 320 毫秒的平滑滑动，并同步切换表单内容。
- 输入框聚焦与按钮按压使用短促反馈，不改变现有登录业务行为。
- 所有循环动效幅度克制，确保输入时不分散注意力。

## 功能与兼容边界

- 不修改学生登录、管理员登录、账号校验、服务器连接和登录后跳转逻辑。
- 保留微信小程序原生输入能力和按钮禁用状态。
- 不在生成图片中制作表单文字、按钮文字或品牌中文，这些内容继续由小程序原生排版承担。
- 图片资源控制体积，保证首屏加载速度；必要时在不明显损失质量的前提下压缩。
- 页面需通过微信开发者工具官方预览编译，并运行现有登录、移动端和管理员登录回归检查。

## 验收标准

- 页面视觉与已选择的“星环空间”方向一致，整体风格统一。
- 登录页能清晰看到重新设计后的敬一书院玻璃标志，不存在白底、空白图、断边或文字伪影。
- 学生和管理员两套表单均可切换、输入和提交。
- 主按钮、输入框、文字在深色背景下具有清晰对比度。
- 常见手机尺寸下布局完整，安全区无内容遮挡。
- 微信开发者工具预览成功，相关自动测试通过。
