## 四、功能矩阵（6 模块，详见画布 S5）

统一反馈语义：**✓ 成功**（Toast 2s / 结果页）· **✗ 失败**（错误聚合条 + Toast 4s）· **… 加载中**（骨架屏 / 按钮 Spinner）· **∅ 空数据**（空状态 + 引导）· **⊘ 无权限**（403 + 返回首页）

| 模块 | 主操作 | 次操作 | 关键前置条件 |
|---|---|---|---|
| A 预约核心 | 时间线选座、提交预约、签到 | 浏览筛选、取消、改签、提前结束、续约 | 信用分 ≥60 · 无未结束预约 · 房间非维护 · 签到窗口 ±15min |
| B 审核与冲突 | 通过、驳回、批量处理 | 转交辅导员、改派、导出 | 驳回原因 ≥5 字 · 同状态可批量 · 乐观锁防并发 |
| C 功能房与规则 | 新增功能房、规则配置 | 编辑 / 停用、座位管理、维护公告 | 停用需无进行中预约 · 删除需无历史预约 |
| D 信用与违规 | 违规登记、黑名单 | 信用明细、恢复信用、规则配置 | 扣分后低于 0 按 0 计并封禁 · 恢复仅超管 |
| E 数据与导出 | 使用率统计、导出 Excel | 导入名单、报表打印 | 超 1 万行分批 · 模板校验 · 脱敏规则 |
| F 权限与系统 | 四层鉴权、公告发布 | 管理员增删、操作日志、学期归档、备份 | JWT → 角色 → 楼栋数据域 → 资源归属 |

## 五、统一设计语言（详见画布 S3 / S4）

**色彩**：主色书院蓝 `#014DB2`；语义色 空闲 `#10B981` / 占用 `#EF4444` / 待审·警告 `#F59E0B` / 使用中 `#0EA5E9` / 不可用 `#9CA3AF`；中性文字 `#0A1628 / #374151 / #6B7280 / #9CA3AF`；背景三档 `#F9FAFB / #FFFFFF / #FFFBEB`。

**字体**：中文 Noto Sans SC，数字·英文 Inter；字阶 28 / 20 / 16 / 14 / 12；字重 400 / 500 / 600 / 700。

**间距**：4px 基线（4/8/12/16/20/24/32/40/48/64）；**圆角**：8 按钮 / 12 卡片输入 / 100 标签；**阴影**：sm `0 1px 2px` / md `0 4px 12px`；**图标** 1.8px 线性，18 / 20 / 24 三档。

**按钮层级**：主操作（实心蓝）> 次操作（描边）> 辅助（文字按钮）> 危险（红色描边 / 实心，二次确认）；统一含加载中与禁用态（`#9CA3AF`）。

**表单校验**：即时校验 + 提交时顶部错误聚合条 + 字段红描边 `#EF4444` + 底部说明；必填标星；禁用提交而非静默失败。

**反馈**：Toast（成功 2s / 错误 4s）、弹窗二次确认、内联提示、骨架屏、空状态（含引导动作）。

**导航**：移动端 62px 状态栏 + 底部 4 Tab（热区 ≥44px）；桌面端 232px 侧边栏 + 64px 顶栏 + 1208px 内容区。

**无障碍**：WCAG AA 4.5:1；输入框高 ≥44；触摸热区 ≥44；支持系统字号缩放与减少动效。

## 六、关键假设与待确认（A1–A20，详见画布 S7）

**账号与登录**：A1 仅微信授权 + 学号绑定（是否接学校 CAS）｜A2 学号绑定后不可自助修改｜A3 姓名学院由学号自动带出｜A4 一微信号绑定一学号（是否存在一人多角色）｜A5 未绑定学号不可用预约功能。

**预约与审核**：A6 自习室按座位×小时，其余按房间×小时｜A7 时长上限（自习 4h / D418 2h / 研讨 3h / 科创 6h / 路演 4h），是否含续约累计｜A8 默认导生会一审，影音室·多功能厅·超 4h 转辅导员｜A9 审核无超时自动处理｜A10 同时段仅持 1 条有效预约｜A11 并发用唯一键兜底，不做锁座 5 分钟｜A12 改签需距开始 ≥2h 且限一次，取消需 ≥30min。

**签到·信用·数据**：A13 签到窗口 ±15min，超时判爽约 -20｜A14 开始后 30min 自动释放（是否推候补）｜A15 信用区间与到期自动恢复至 60｜A16 连续 10 次无违规 +5 的统计口径｜A17 违规与黑名单跨楼栋跨学期生效｜A18 导出脱敏口径｜A19 学期归档后历史只读｜A20 仅订阅消息 + 站内消息，是否需短信兜底。

> 以上均为保守默认取值，任一变更只影响局部页面与规则配置，不推翻整体信息架构。

## 七、可复用组件库（30 个，页面「03-可复用组件库」）

本轮已将 S4 的交互元素沉淀为画布组件（`reusable: true`），可直接实例化复用，保证 44 页视觉一致并降低开发还原成本。

| 分类 | 组件 | 说明 |
|---|---|---|
| 按钮 | Button/Primary、Secondary、Text、Danger、Disabled | 主 / 次 / 文字 / 危险 / 禁用 5 态 |
| 表单 | Field/Default、Field/Error | 正常态与错误态输入框 |
| 状态标签 | Tag/Pending、Approved、Using、Done、Rejected、NoShow、Counselor | 覆盖预约 7 态 |
| 筛选导航 | Chip/Default、Chip/Active、Tab/Active、Tab/Default、Search/Input | 顶部筛选与 Tab 切换 |
| 卡片 | Card/Room、Card/Stat、Card/Notice | 房间卡 / 统计卡 / 通知卡 |
| 反馈 | Toast/Success、Toast/Error、Empty/State、Modal/Confirm、Alert/ErrorBar | 成功 / 错误 / 空态 / 确认弹窗 / 错误条 |
| 容器 | Nav/Sidebar、Bar/Topbar、Row/Table | 侧边栏 / 顶栏 / 表格行 |

组件使用方式：在设计文件中以「实例（instance）」引用，通过 `;` 路径覆盖子节点文案即可生成同风格不同内容的页面元素。
