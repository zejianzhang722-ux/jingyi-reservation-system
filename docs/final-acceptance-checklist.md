# 最终验收清单

## 1. 验收信息

验收时记录：

- 发布版本与 Git 提交号；
- API 和管理后台镜像摘要；
- 验收日期、环境和负责人；
- MySQL、Redis、服务器规格和测试数据规模；
- 所有 GitHub Actions 工作流链接；
- 性能、备份、恢复和发布演练证据。

## 2. 认证与权限

- [ ] 学生、管理员、辅导员和超级管理员登录正常；
- [ ] 访问令牌与刷新令牌不能混用；
- [ ] 退出后令牌失效；
- [ ] 普通管理员不能访问其他楼栋数据；
- [ ] 学生不能查看或修改他人预约；
- [ ] 超级管理员专属接口有后端权限校验；
- [ ] 密码、令牌和密钥未出现在日志、前端或仓库中。

## 3. 预约闭环

- [ ] 房间列表、详情、座位和时间轴正常；
- [ ] 普通房间和座位房间均可成功预约；
- [ ] 同一用户重复提交只产生一条预约；
- [ ] 并发请求不能重复占用相同时间槽；
- [ ] 修改、取消、重新预约正常；
- [ ] 候补加入、退出和转正式预约正常；
- [ ] 审批通过和拒绝使用条件更新，重复处理返回冲突；
- [ ] 取消和拒绝后槽位被释放；
- [ ] 学生预约列表和详情字段完整。

## 4. 签到与信用

- [ ] 动态签到凭证具有短有效期；
- [ ] 已使用凭证不能重放；
- [ ] 学生不能调用工作人员签到接口；
- [ ] 扫码、人工签到、签退和状态查询正常；
- [ ] 爽约、违规和良好行为的信用分变动正确；
- [ ] 信用限制和解除规则正常。

## 5. 通知与实时事件

- [ ] 站内通知写入成功；
- [ ] 同一业务事件不会重复生成通知；
- [ ] Outbox 领取、重试和死信正常；
- [ ] 多实例下不会重复投递同一事件；
- [ ] WebSocket 只允许有效身份连接；
- [ ] 房间状态和预约事件可跨实例广播；
- [ ] 外部消息失败不影响核心预约事务提交。

## 6. 管理端

- [ ] 网页后台和小程序管理员端均可登录；
- [ ] 预约审批、房间、座位、公告、反馈和信用管理正常；
- [ ] 管理员列表和统计均遵守楼栋范围；
- [ ] 大列表具有分页和筛选；
- [ ] 导出结果与筛选条件一致；
- [ ] 页面没有测试文案、调试地址或内部说明；
- [ ] 移动端无明显重叠、遮挡和不可点击区域。

### 双端一致性补充验收
- [ ] 三种管理员身份分别核对可见入口、可处理范围和楼栋范围；
- [ ] 普通预约审核与辅导员重点审核分开显示、分级处理；
- [ ] 列表或详情加载失败时显示真实错误，重新加载后可恢复，不出现虚构数据；
- [ ] 管理员预约详情遵守当前角色和楼栋范围，并只显示审批所需信息；
- [ ] 数据概览、待办数量和使用排行均遵守当前角色与楼栋范围；
- [ ] 管理页、首页和“我的”页之间切换不重复启动页面，返回后数据可正常刷新；

- [ ] 使用导生管理员、辅导员、超级管理员三种身份，分别登录网页后台和管理员小程序，核对各自可见入口与不可见入口；
- [ ] 导生管理员可处理普通审核队列，但不能进入辅导员重点审核和海报审核；
- [ ] 辅导员和超级管理员可分别进入普通审核队列与辅导员重点审核队列，并可进入海报审核；
- [ ] 在网页后台完成一次通过或拒绝后，小程序刷新可看到同一结果；在小程序完成一次通过或拒绝后，网页后台刷新可看到同一结果；
- [ ] 功能房维护、楼栋维护、座位维护、开放规则、账号管理、信用配置、海报位置、公告管理、操作日志和数据备份仅在电脑后台提供，不作为小程序缺失项；
- [ ] 网页后台发布或修改公告后，小程序学生首页刷新可读取同一公告内容。
