# 敬一书院功能房预约平台 · 图文操作资料库

双击 [index.html](index.html) 即可离线阅读，不依赖后台服务或外网。资料库分为微信小程序宿生端、微信小程序管理员端、网页后台管理端，共 59 个实际界面页面。左侧按业务分类，三端切换始终悬浮在页面顶部；搜索可跨三端查找，键盘 `/` 可快速打开搜索。

每一页均包含页面版式、当前运行版本的完整页面截图、与截图控件对应的编号标注、分步操作、注意事项、业务流程图和相关页面跳转。小程序截图通过自动下滑拼接得到；自习室与共享空间时间轴还附有右滑拼接的横向全览。网页后台截图会展开页面内部的滚动区域。截图分别来自微信开发者工具模拟器和本地网页后台，使用测试数据采集。动态图形码在资料库展示时被遮挡，不可用作签到凭证。指向或用键盘选中编号、说明卡时，对应两处会同步突出。

如需校准标注位置，请在本目录的项目根目录运行 `node docs/manual/tools/serve-editor.cjs`，然后打开 [本地标注校准器](http://127.0.0.1:4179/tools/annotation-editor.html)。选择页面后拖动标注框、拖动右下角调整大小，或填写精确坐标；点击“保存标注”后，已经打开的本地服务版资料库会同步更新。直接双击打开的离线版仍可阅读，但要重新打开页面才能读取新保存的位置；离线版不能直接写入文件。保存结果位于 `annotation-layouts.js`，不会改动原始截图。

不同端的权限与流程已经分别说明：宿生发起预约并签到；移动管理员处理值班审核和现场查询；组团审核、房间规则及高级管理主要在网页后台。资料库不会把移动端没有的按钮描述为已有功能。时间轴截图取自完成制度确认后的真实界面；空对比列表、未选房规则页及没有正式备份的测试环境，均按真实状态标明，未伪造成功状态。

校验命令：

```powershell
node docs/manual/tools/verify.cjs
node docs/manual/tools/verify-browser.cjs
node docs/manual/tools/test-stitch.cjs
node docs/manual/tools/test-editor-server.cjs
node docs/manual/tools/verify-editor-browser.cjs
```

截图放在 `assets/miniapp` 和 `assets/web`，复制资料库时须连同 `assets` 一起复制。资料库不包含测试账号密码。
